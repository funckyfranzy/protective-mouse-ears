# Protective Mouse Ears 🐭✨

Leuchtende Protective Ears für den **40C3** (Model Citizens): ESP32-C3 Super Mini,
WS2812B-LED-Streifen über den ganzen Haarreif, Bewegungssensor, Steuerung per Handy über Bluetooth.

- [PLAN.md](PLAN.md) – Plan, Verkabelung, Stand
- [ANFORDERUNGEN.md](ANFORDERUNGEN.md) – Anforderungen an die eigene Firmware
- [MUSTER.md](MUSTER.md) – JSON-Format für Leuchtmuster (Atmen, Herzschlag, Ohrenzucken …)
- `Styleguide.pdf` – 40C3-Styleguide (CC0)
